# BASIC_CPP_PROGRAMS

A collection of basic C++ programs covering fundamental programming concepts. This repository is intended for beginners who are learning C++ and want to understand core concepts through simple and well-structured programs.


## Topics Covered


### 1. Basic C++ Programming

* Basic C++ Programs
* Input / Output
* Variables & Data Types


### 2. Operators

* Arithmetic Operators
* Relational Operators
* Logical Operators
* Assignment Operators
* Increment / Decrement Operators
* Ternary Operator


### 3. Conditional Statements

* If-Else Statements
* Nested If Statements
* Else-If 
* Switch Statements


### 4. Loops

* For Loop
* While Loop
* Do-While Loop


### 5. Pattern Printing

* Nested Loops
* Star Patterns
* Number Patterns
* Alphabet Patterns


### 6. Functions

* Function Definition, Declaration, and Calling
* Function Parameters and Return Types
* Function Arguments
* Function Overloading
* Scope of Variables (Local, Global)


### 7. Pointers

* Pointer Basics
* Pointer Arithmetic
* Double Pointers
* Dynamic Memory Allocation using Pointers


### 8. Arrays

* Arrays Basics (Declaration, Initialization, Traversal)
* Passing Arrays to Functions
* Arrays and Pointers


### 9. Vectors

* Vector Basics (Declaration, Initialization, Traversal)
* Vector STL Functions (Push_back, Pop_back, Size, Sort, etc.)
* Passing Vectors to Functions (By Value, By Reference)
* Custom Comparator for Sorting Vectors
* Iterators in Vectors


### 10. 2D Arrays

* 2D Arrays Basics (Declaration, Initialization, Traversal)
* Passing 2D Arrays to Functions


### 11. 2D Vectors

* 2D Vectors Basics (Declaration, Initialization, Traversal)
* Passing 2D Vectors to Functions (By Value, By Reference)


### 12. Strings

* String Basics
* String Manipulation
* String Functions (Length, Substring, Concatenation, etc.)
* Operations on Strings 
* Classes of String (Stringstream)
* Difference between String and Character Array


### 13. Sorting Algorithms

* Bubble Sort
* Selection Sort
* Insertion Sort


### 14. Searching Algorithms

* Linear Search
* Binary Search

## Purpose

The goal of this repository is to:

* Practice C++ programming fundamentals.
* Build a strong foundation before moving to advanced topics.
* Provide simple reference implementations for common concepts.
* Help students during academic preparation and coding practice.


## Notes

* Programs are written for learning purposes.
* Most programs are intentionally kept simple and easy to understand.
* Some programs may demonstrate multiple approaches to the same problem.
