# About Nested If-Else

A **nested if-else** means putting one `if-else` statement inside another. It’s useful when you need to check multiple conditions in a structured way.

---

## 🔹 Basic Idea

Instead of checking everything in one condition, you break decisions into levels.

---

## 🔹 Syntax (General)

```c
if (condition1) {
    if (condition2) {
        // code if both condition1 and condition2 are true
    } else {
        // code if condition1 is true but condition2 is false
    }
} else {
    // code if condition1 is false
}
```
