#   Ternary Operator

The **ternary operator** in C++ is a short form of `if-else`.

It is called **ternary** because it uses **3 operands**:

1. Condition
2. Value if condition is true
3. Value if condition is false

---

# 🔹 Syntax

```cpp 
(condition) ? expression1 : expression2;
```

* If condition is **true** → `expression1` executes
* If condition is **false** → `expression2` executes

---

# 🔹 Advantages

* Short and compact code
* Easy for simple conditions
* Replaces small `if-else` statements

---

# 🔹 Disadvantages

* Hard to read if conditions become complex
* Not good for large logic

---


# 🔹 Important Note

The ternary operator returns a value, so it is often used in:

* Variable assignment
* Printing results
* Simple decision making

---

# 🔹 Formula to Remember

```cpp 
condition ? true_part : false_part;
```
